# ytdl-hoarder frontend

Next.js 16 (Turbopack, Tailwind v4) UI, statically exported in production and
served by the backend. See the root [README](../README.md) and
[AGENTS.md](../AGENTS.md) — the frontend toolchain section there documents the
non-obvious build constraints.

Dev server runs in Docker: `task up` from the repo root.
